# FloodNet database design

The database is PostgreSQL, accessed with `node-postgres` and parameterized SQL. No ORM is planned.

## Migration

The first migration is `server/db/migrations/001_initial_schema.sql`. It creates the core authentication, reporting, alert, evacuation, notification, evidence and audit tables.

## Important constraints

- New reports default to `PENDING_REVIEW`.
- Report review notes are required when rejecting a report or requesting more information.
- Occupancy cannot be negative or greater than capacity.
- Available spaces are generated by PostgreSQL.
- Alert expiry must be later than its start time.
- Lower-cased email values are unique through a functional index.

## Seed data

`server/db/seeds/001_reference_data.sql` inserts the four roles, demonstration zones and centre facility types. Development users will be added through a controlled seed process after authentication is implemented.
